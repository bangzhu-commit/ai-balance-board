# 自定义站点：添加、导入与测试

从 v0.5.0 起，可以添加自己的 HTTPS 额度站点。看板执行固定读取规则，日常查询不调用模型。首次让 Codex、WorkBuddy 等 Agent 分析站点、生成或修复规则，可能使用该 Agent 的模型额度。

这不是填网址后就能识别任何网站的功能。每个站点需要验证数据来源、登录方式和额度口径；不兼容的站点会明确失败，不把失败显示成零余额。

## 普通用户操作

1. 从看板齿轮进入“服务与设置”，在“选择服务”或“检查与连接”页找到“自定义站点”，点击“添加站点”。
2. 填写你想显示的名称，以及网站的 HTTPS 地址，例如 `https://relay.example.com`。不要填带密码、token 或查询参数的链接。
3. 点击“复制给 Agent 的接入任务”，交给有浏览器 / Computer Use 与配置生成能力的 Agent。也可直接使用[完整接入指引](agent-site-onboarding.md)。登录、验证码及系统授权由你本人完成。已有经过核实的配置可跳过这一项。
4. 把 Agent 返回的 JSON 粘贴进输入框，或点击“选择 JSON 文件”。点击“检查配置”，确认预览中的域名、字段、单位与含义正确，再点击“添加站点”。此时不自动联网或开启监控。
5. 展开站点，点击“打开登录窗口”。在看板自己的窗口中登录；该会话与 Chrome 独立，不能直接复制浏览器登录。
6. 返回设置，点击“测试连接”。测试结果出现后，把每项数值、单位以及“已用 / 剩余”含义与网站页面对照。必须确认不是加载中的占位值、总额度或其他账户的数字。
7. 确认一致后勾选核对项，在 5 分钟内点击“确认并开启自动查询”。过期则重测。看板直接沿用这次新读数，之后约 5 分钟查询一次。

以后可单独暂停、重新导入或移除站点。测试会暂停原监控；编辑配置后必须重新测试与确认。测试等待时可取消。最多保存 12 个自定义站点，每个站点有独立登录会话和查询调度。

登录 Mac 后自启需在“运行方式”中开启。唤醒、联网恢复后合并补查，不追补关机期间的历史次数。离线、登录过期、限流或规则失效时显示状态并保留上次读数。

## 当前能接什么

| 方式 | 适合的站点 | 运行方式 |
| --- | --- | --- |
| `json` | 登录后，额度页面通过同一站点的 GET 接口返回 JSON | 固定程序请求已配置路径，并按 JSON Pointer 读取数字 |
| `dom` | 没有适合的接口，但额度数字存在于稳定、唯一的网页元素中 | 加载额度页，按 CSS 选择器读取元素文本 |

优先使用 JSON 模式。DOM 模式会运行网站自己的页面脚本，选择的必须是正常只读额度页；不要填写聊天、生成、充值或账户变更页面。接口是否只读需要实际核实，不能仅凭 GET 方法判断。

首版仅接受公开 HTTPS 域名和同源相对路径，不支持 IP 字面地址、本机地址、非标准端口、查询参数、自定义请求头、请求体、API key、跨域额度接口、任意 JavaScript / shell 或自定义正则表达式。某些必须使用 Authorization 头或带查询参数的正常额度接口因此也无法接入，不能通过把凭据塞进路径等方式绕过。

登录窗口可处理 HTTPS 同窗口跳转；要求外部浏览器、弹窗或专用协议的登录方式暂不保证支持。必须持续验证码、只能靠视觉理解、数字绘制在 canvas 中、额度位于无法访问的 iframe 中，或者没有稳定读取规则的站点，不能承诺无人值守监控。DOM 选择器失效后需要更新配置。

## schemaVersion 1 配置规范

文件必须是 UTF-8 JSON，最大 64 KiB。未知字段会被拒绝。示例只是合成模板，没有连接任何实际服务：

- [JSON 接口示例](../examples/custom-sites/json-example.json)
- [网页元素示例](../examples/custom-sites/dom-example.json)

| 字段 | 规则 |
| --- | --- |
| `schemaVersion` | 固定为整数 `1` |
| `name` | 看板显示名称，1–50 字符 |
| `origin` | HTTPS 站点根地址，不含账号、密码、路径、查询参数或片段，例如 `https://relay.example.com` |
| `loginPath` | 登录页相对路径，例如 `/login` |
| `pagePath` | 已登录额度页相对路径，例如 `/dashboard` |
| `mode` | `json` 或 `dom` |
| `requestPath` | JSON 模式必填：已验证的同源 GET 额度路径，例如 `/api/usage`；DOM 模式省略 |
| `success` | JSON 模式可选：`{"path":"/success","equals":true}`；比较布尔值、数字或短字符串，按实际响应设置 |
| `metrics` | 1–6 个额度字段，`id` 不重复 |

相对路径以一个 `/` 开头，不接受查询参数、片段、转义、目录跳转或跨站地址。常见生成、支付及账户修改路径会被拒绝，但校验不能替代对网站业务含义的核实。

每个 `metrics` 元素：

| 字段 | 规则 |
| --- | --- |
| `id` | 小写字母开头，后续可用小写字母、数字、`_`、`-`，共 1–32 字符 |
| `label` | 显示名称，1–40 字符，例如“本月剩余” |
| `unit` | 明确单位，1–16 字符，例如 `USD`、`CNY`、`token`、`次`、`%`；不同单位不相加 |
| `meaning` | `balance`（余额）、`remaining`（剩余）、`used`（已用） |
| `value` | JSON 模式用 JSON Pointer，例如 `/data/balance`；DOM 模式用 CSS 选择器，例如 `#remaining` |
| `operation` | 默认 `value`，直接读取；`remaining` 表示 `total - value`，此时 `value` 必须指向已用量且 `meaning` 必须为 `remaining` |
| `total` | 可选的总额定位规则；`operation=remaining` 时必填。使用同一种定位方式 |
| `multiplier` | 默认 `1`，将结果乘以明确核实的固定换算倍率；范围 `1e-9` 至 `1e9` |
| `prefix` / `suffix` | 默认空字符串；仅剥去精确匹配的数字前后缀，例如 DOM 文本 `87%` 对应 `suffix:"%"`。每项最多 20 字符 |

JSON Pointer 支持对象属性、数组固定索引、`~0` / `~1` 转义。没有通配符、循环或求和表达式；需要复杂聚合的服务仍需开发专用适配器。

DOM 只读取唯一元素的 `textContent`，不读取密码、Cookie、localStorage、任意属性或输入框值；选择器找不到、匹配多个元素或文本不是确定数字时失败。数字支持小数点和规范千位逗号，不猜测欧式小数逗号、“无限”、加载占位符或计算公式。剥离前后缀后必须只剩完整数字。

剩余百分比不能大于 100%，已用百分比不能小于 0；允许负剩余或超过 100% 的已用值表达超额。负金额余额也会保留，不强行改成零。

自定义站点首版不解析动态重置时间，也不自动推断币种、兑换比例、套餐归属或周期。JSON 解析内容上限 512 KiB；每条 DOM 文本上限 4096 字节。超过范围时应寻找更小且明确的读取来源。内容上限不是对网站全部下载流量的硬限制。

## 测试失败时

- **需要登录**：在该站点自己的登录窗口完成登录，再测试。Chrome 已登录不代表看板会话已登录。
- **稍后重试 / 限流**：暂停频繁手动测试，等待网站限制恢复；不要用更密集轮询绕过限制。
- **字段无效 / 未取得有效额度**：检查成功标记、JSON Pointer、选择器、前后缀与单位。登录页、加载占位值和非数字文本都不能当作余额。
- **禁止跳转 / 站点不匹配**：确认 `origin` 和实际额度接口同源；跨域接口不在首版支持范围。
- **配置无法保存**：检查本机存储权限；看板不会把保存失败显示为成功。已有配置损坏时先备份修复，避免覆盖。

移除站点只删除看板配置和读数并停止查询，不退出网页账号，专属 WebKit 会话保留。不要把真实配置、地址、账号、响应或额度截图提交到公开仓库；问题反馈只提供脱敏结构与错误类型。详见[隐私说明](privacy.md)。

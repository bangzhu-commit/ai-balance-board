# AI 额度看板 v0.7.2 · 固定 JSON 额度汇总

自定义站点现在可以按已确认的 JSON 规则汇总多份订阅，计算总额减已用，避免固定读取第一条订阅而漏算。

- [Mac 应用 ZIP](https://github.com/bangzhu-commit/ai-balance-board/releases/download/v0.7.2/AI-Balance-Board-0.7.2-macos-arm64.zip) · [SHA256](https://github.com/bangzhu-commit/ai-balance-board/releases/download/v0.7.2/SHA256SUMS.txt)
- Apple Silicon（M 系列）、macOS 14+。[安装说明](https://github.com/bangzhu-commit/ai-balance-board/blob/main/docs/installation.md)

集合配置使用 schemaVersion 2，只允许同源只读 JSON 查询、固定筛选和求和，必须检查成功标记；不导入脚本或凭据。缺失、类型错误、非数字、越界及失败响应不会伪装成零。真正的空数组或无匹配项可显示零。

[配置规范与合成示例](https://github.com/bangzhu-commit/ai-balance-board/blob/main/docs/custom-sites.md)已同步。日常查询与计算均不调用模型。新站仍需登录、测试并核对读数后才能启用；旧站应在新站验证成功后停用。

旧 schemaVersion 1 继续可用。含集合连接的本机配置需要 v0.7.2+；回退旧版会暂停自定义连接并保留文件。此版本仍为 ad-hoc 签名预览版，未做 Apple 公证，无自动更新。

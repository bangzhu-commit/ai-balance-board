# AI 额度看板 v0.5.0 · 自定义站点预览版

现在可以在设置中添加自己的站点，导入读取配置、登录、测试并核对额度后，开启后台自动查询。首次适配可请 Codex、WorkBuddy 等 Agent 帮忙；看板日常查询不调用模型。

## 下载与开始

- [Mac 应用 ZIP](https://github.com/bangzhu-commit/ai-balance-board/releases/download/v0.5.0/AI-Balance-Board-0.5.0-macos-arm64.zip)：Apple Silicon（M 系列芯片）、macOS 14+。
- [SHA256 校验文件](https://github.com/bangzhu-commit/ai-balance-board/releases/download/v0.5.0/SHA256SUMS.txt)。
- [安装与首次系统拦截处理](https://github.com/bangzhu-commit/ai-balance-board/blob/main/docs/installation.md)。
- [添加站点与配置规范](https://github.com/bangzhu-commit/ai-balance-board/blob/main/docs/custom-sites.md) · [给 Agent 的接入指引](https://github.com/bangzhu-commit/ai-balance-board/blob/main/docs/agent-site-onboarding.md)。

解压后把 app 放入“应用程序”。从旧版更新时先退出看板，再替换同一路径的 app；Chrome 连接器按安装说明重新注册和加载。配置会保留，新增自定义站点默认不查询，必须经过测试与核对。

## 新功能

- 设置中提供添加站点、JSON 文件导入或粘贴、规则检查与预览。
- 内置可复制给 Agent 的任务与两份合成示例；示例使用虚构域名，不含真实站点配置或账号数据。
- 同源 JSON 额度接口与固定 CSS 元素两种读取方式；固定单位转换与总额减已用。
- 每站点独立 WebKit 登录会话，最多 12 个自定义站点；不能直接借用 Chrome 会话。
- 测试读数需人工核对后启用；修改配置、重新登录或切换账号后重新验证。
- 测试、手动刷新、定时刷新共用调度，取消、更新、移除后不接收旧回包；确认测试后沿用当前读数，不重复立即查询。
- 登录自启沿用已有开关，唤醒与网络恢复后合并补查；错误保留旧值并标记状态。
- 内置中转站的设置文案采用通用名称；Codex 与 Grok Bot 接入保持原有方式。

## 范围与限制

首版自定义配置仅适用于已经核实的同源 HTTPS 只读接口或稳定网页元素。暂不支持认证请求头、查询参数、跨域 API、任意脚本、复杂聚合或动态重置时间。需要弹窗、外部浏览器、持续验证码或每次视觉推理的站点不能保证接入；配置格式通过不等于连接成功。

初次使用 Agent 分析站点和后续修复规则可能消耗 Agent 模型额度；日常查询由固定程序执行。登录、验证码与授权由用户完成，真实站点配置留在本机。删除站点不退出网页账号，WebKit 会话保留。

应用仍为 ad-hoc 签名，未完成 Developer ID 签名或 Apple 公证；首次被“无法验证开发者”拦截时按安装说明处理。Grok Bot 的 Chrome 扩展仍需手动加载。没有 Intel 支持或自动更新。

## 验证范围

发布前检查覆盖配置校验、数值解析、旧配置迁移、动态调度、测试确认、取消与旧回包隔离、查询规则、界面离屏渲染及已有连接器回归。测试使用合成数据，不调用模型、不使用个人账号。远端构建结果以 [GitHub Actions](https://github.com/bangzhu-commit/ai-balance-board/actions) 对应提交为准。

尚未逐一验证其他真实站点，也未完成干净 Mac 的完整首次安装和长期运行验收。反馈时使用[问题模板](https://github.com/bangzhu-commit/ai-balance-board/issues/new/choose)，不要提交凭据、真实配置、个人额度或原始响应。

# AI 额度看板 v0.7.1 · 粘贴快捷键修复

修复“添加网站 / 中转站”输入框不能用 ⌘V 粘贴的问题。应用现在提供标准编辑菜单，网址、名称和 JSON 等文本输入使用系统的复制、剪切、粘贴、全选、撤销与重做命令。

## 使用

退出旧版并替换应用，重新打开后进入“添加网站 / 中转站”，点击网址输入框，再按 ⌘V。网址输入后才会启用“复制给 Agent 的接入任务”。原有连接配置与等比缩放保留。

此次修复只补齐应用内的标准编辑命令，不读取后台剪贴板、不监听全局快捷键。网址和账户仍保存在本机，不公开用户站点。日常额度查询不调用模型。

完整检查见 [GitHub Actions](https://github.com/bangzhu-commit/ai-balance-board/actions) 和[发布验收表](https://github.com/bangzhu-commit/ai-balance-board/blob/main/docs/release-checklist.md)。此版本仍为 ad-hoc 签名预览版，未做 Apple 公证，无自动更新。

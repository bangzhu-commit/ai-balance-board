# AI 额度看板 v0.6.0 · 工具接入与可调窗口预览版

常用 AI 工具现在放在接入首页；看板支持拖动、调整大小、保存位置和尺寸，默认不置顶，可以按需开启。

普通用户请选择应用 ZIP，源码 ZIP 面向开发者。退出旧版后替换同一路径的 app，保留应用数据目录与偏好；已有配置和登录会话继续保留。使用 Chrome 连接器的用户按安装说明完成更新后重连。

## 这次改了什么

- **工具优先**：Codex、Claude、WorkBuddy、千问办公、豆包办公、Grok Bot、Muse 及“其他 AI 工具”。所有入口都能自定义；明确区分内置连接与需配置。工具名称不会自动产生读取规则。
- **一次接入，固定查询**：只知道工具名称时，可以先复制任务，请具备 Computer Use 能力的 Agent 核实产品、账号、套餐及真实额度来源。网站 / 中转站放在单独入口，支持导入、测试、核对后启用。
- **窗口更灵活**：原生拖动区域独立于数据界面，刷新期间不替换拖动层。拖边缘或右下角调整大小，刷新和重新打开后保持用户尺寸；最小尺寸 300 × 240。
- **不强制置顶**：默认普通窗口层级，菜单栏和设置均可开启置顶。“恢复看板位置与大小”可找回窗口。
- **减少无效请求**：修复限流与唤醒、联网恢复交叠时过早重查的问题。当前进程内每项服务至少冷却 300 秒；重复手动刷新、重新启用和自定义测试不能绕过，其他服务照常查询。
- **更容易维护**：设置显示版本和构建号，提供下载更新、安装帮助与脱敏诊断；补齐首次接入、升级保留数据与错误排查说明。

## 接入范围

Codex 内置连接查询本机 Codex CLI 所登录的 ChatGPT 套餐额度。Grok Bot 的现有内置连接读取对应 Cursor 账号，并非 xAI / Grok 官方通用额度接口。旧中转站连接继续保留。

Claude、WorkBuddy、千问办公、豆包办公、Muse 等是自定义接入入口，**没有声称已获得这些产品的通用额度适配**。需要实际可访问的 HTTPS 额度页、同源只读 JSON 或稳定网页数值元素，并逐项测试；不支持的来源应报告限制，不能虚构数值。自定义配置契约仍为 schemaVersion 1，最多 12 条。

看板日常不调用模型。首次请 Agent 分析或后续修复配置会使用所选 Agent 额度；登录、验证码和权限由用户完成。

## 验证与限制

本轮包含离线解析、调度、取消与旧回包隔离、请求/响应边界、实际 WebKit 内存页面、原有连接器回归，以及原生隐藏窗口上的输入分派、缩放、位置/尺寸、置顶切换检查。界面使用合成数据离屏检查，未访问个人账号。具体检查记录见[发布验收表](https://github.com/bangzhu-commit/ai-balance-board/blob/main/docs/release-checklist.md)，远端构建以 [GitHub Actions](https://github.com/bangzhu-commit/ai-balance-board/actions) 对应提交为准。

间歇拖动故障未在真实用户桌面复现；本轮修复了刷新与拖动区域耦合的问题并增加回归。真实鼠标边缘缩放、多屏拔插、干净 Mac 安装和各平台首次登录仍需实际用户验证，不以离屏测试替代。

当前仍是 ad-hoc 签名预览版，没有 Developer ID、公证、Intel 支持或自动更新；Chrome 扩展需手动加载。限流冷却不跨退出持久化，也不代替平台可能要求的更长等待。不要通过关闭系统防护或反复重启绕过限制。

# AI 额度看板 v0.4.0 · 预览版

一个可悬浮在 Mac 桌面的 AI 额度看板。集中查看最近额度，后台查询不调用模型、不消耗模型推理 token。

## 下载

- [Mac 应用 ZIP](https://github.com/bangzhu-commit/ai-balance-board/releases/download/v0.4.0/AI-Balance-Board-0.4.0-macos-arm64.zip)：普通用户下载这一项。
- [SHA256 校验文件](https://github.com/bangzhu-commit/ai-balance-board/releases/download/v0.4.0/SHA256SUMS.txt)：核对下载内容。
- [Release 详情](https://github.com/bangzhu-commit/ai-balance-board/releases/tag/v0.4.0)：查看版本资产与后续说明。

需要 **Apple Silicon（M 系列芯片）与 macOS 14+**，不支持 Intel Mac。解压后把 app 拖入“应用程序”，双击打开并按首次设置连接。普通用户不要下载 “Source code”；运行 app 及原生设置不需要 Python 或 Node.js。

## 这个版本包含什么

- 首次设置：选择服务 → 检查与连接 → 设置后台运行。可只启用一项，也可跳过后再连接。
- 支持当前内置适配的中转站（暂不支持自定义站点）、Codex ChatGPT 套餐额度，以及通过 Chrome Cursor 账号查询的 Grok Bot 额度。
- 桌面悬浮、标题拖动、菜单栏收起/恢复；每项服务独立刷新、退避和错误状态。
- 每约 5 分钟刷新，登录、唤醒和网络恢复后合并补查，避免重复查询。
- 原生设置提供登录自启、本机组件注册/移除、浏览器绑定重置、清除旧读数和脱敏诊断导出。
- 包含本机连接器资源，无需下载源码才能注册；诊断不会自动上传。
- MIT License，附应用包与源码包 SHA256。

## 使用前了解

应用目前只有 **ad-hoc 签名，未做 Developer ID 签名或 Apple 公证**。首次提示“无法验证开发者”时，确认下载来源及校验值后，可在“系统设置 → 隐私与安全性”中为这个 app 选择“仍要打开”。详见[首次拦截处理步骤](https://github.com/bangzhu-commit/ai-balance-board/blob/main/docs/installation.md#首次打开被-macos-拦截)。若提示损坏或恶意软件，请停止安装；不要关闭 Gatekeeper 等防护。

Grok Bot 连接器尚未上架 Chrome Web Store，需要在 Chrome 120+ 手动加载本地扩展。Chrome 需要运行并登录对应 Cursor 账号，可以在后台。扩展仅传递额度字段，不读取或导出 Cookie、密码或聊天内容。

当前仅支持上述三项服务，每项一个账号。WorkBuddy、千问办公、Qoder、其他中转站及通用 Cursor 卡片尚未接入。中转站与 Grok Bot 使用官网内部额度接口，后续网站变化可能需要更新适配器。离线或失败时保留旧读数并标明状态，不冒充实时数据。

没有自动更新、一键完整清除平台会话或 Intel 支持。完整安装、升级和卸载步骤见 [安装与维护](https://github.com/bangzhu-commit/ai-balance-board/blob/main/docs/installation.md)。

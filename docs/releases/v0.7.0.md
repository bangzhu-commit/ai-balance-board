## 整体缩放

- 拖动边缘或右下角手柄，固定比例缩放整个看板，按钮和拖动区域随显示比例同步。
- 比例范围为 80%–160%，屏幕可用区域会进一步限制。达到下限后停止缩小，避免文字过小。
- 缩小保持原本可见的逻辑区域；连接多时仍可滚动。不会为了适应更小窗口而把原本可见的卡片裁掉。
- 基准高度适应卡片自然高度，单卡不会留下大量空白；多连接超过上限时滚动。保存位置和缩放比例，旧版尺寸迁移成合适比例；更新内容时保留比例。
- 菜单栏“恢复默认大小”恢复默认比例并尽量保持左上角位置，受屏幕空间限制时自动缩放或归位；“恢复看板位置与大小”同时恢复位置。默认不置顶，原开关保留。

## 粘贴网址 → 交给 Agent → 拖入配置 → 测试

1. 在“添加网站 / 中转站”粘贴网址，首页、登录页、仪表盘链接或裸域名均可作为起点。看板只保留 HTTPS 域名，不复制页面路径、查询参数和片段；不会自动打开网页。
2. 复制给 Agent 的接入任务，交给具备 Computer Use 能力的 Agent。由用户完成登录，Agent 核实正常只读额度来源，交付可重复读取的配置文件，不只抓一次余额。
3. 拖入或选择一个本机 JSON 配置文件，自动检查格式与域名，并预览指标；确认来源后保存。名称编辑和原始 JSON 放在默认折叠的高级设置中。
4. 在看板登录、测试，核对金额、单位和已用 / 剩余含义后开启。保存或格式检查成功不代表已连接。

仅接受不超过 64 KiB 的本机 UTF-8 JSON；不运行导入脚本、不导入 Cookie 或 API key。导入本身不联网，也不自动启用监控。AI 工具入口仍支持先只提供名称，请 Agent 核实官网；自定义配置格式保持 schemaVersion 1。

## 验证和边界

发布检查覆盖 URL 规范化与隐私、配置文件读取、导入状态变更、比例迁移与限制、隐藏原生窗口事件、实际界面缩放渲染，以及现有查询机制回归。具体结果见[发布验收表](https://github.com/bangzhu-commit/ai-balance-board/blob/main/docs/release-checklist.md)和对应 [GitHub Actions](https://github.com/bangzhu-commit/ai-balance-board/actions)。

网址不会自动适配所有网站；仍需可靠的同源只读接口或稳定页面元素。初次 Agent 分析与规则修复消耗 Agent 额度，看板日常查询不调用模型。

这是 ad-hoc 签名预览版，未做 Apple 公证，没有 Intel 支持或自动更新。更新文件后需退出旧进程再打开，当前窗口才会使用新版；已有配置和登录会话保留。

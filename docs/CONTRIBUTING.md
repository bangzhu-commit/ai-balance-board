# 支持与贡献

项目采用 [MIT License](../LICENSE)，当前发布为预览版。欢迎通过 issue 反馈问题、提出接入需求，或提交范围明确的 pull request。

提出问题前确认版本与支持范围，并阅读隐私说明。新服务需求请提供公开的官方产品名称、额度页面说明和计量单位，不提供账号或凭据。

接入必须满足：查询不调用模型、明确数据来源/单位/刷新时间、未知不填零、失败不冒充实时、登录由用户完成、权限仅限必要来源。内部接口须标明维护风险。不同服务或账号的共享额度不能简单相加。

维护者审阅改动时应核对最小权限、离线测试、失败状态、首次使用和升级路径。未经明确授权，不上传用户数据，不自动安装扩展，不改变浏览器安全设置。

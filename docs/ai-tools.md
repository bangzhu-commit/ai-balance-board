# 先选择工具，再确认额度来源

工具目录用于缩短接入步骤。点击名称不会登录账号、请求额度或运行 Agent；只有现有内置连接，或者经过测试并确认的自定义连接，才能进入日常监控。

## 选择哪条路径

| 入口 | 当前可用路径 | 需要确认的事 |
| --- | --- | --- |
| Codex | 内置连接；也可自定义 | 内置查询本机 Codex CLI 的 ChatGPT 登录账号，可能与桌面应用不同；API 余额与订阅额度分开 |
| Claude | 自定义 | 先确认是聊天订阅、Claude Code 对应套餐还是 API 账单，再找目标来源 |
| WorkBuddy | 自定义 | 确认账号、套餐和额度页；不要只凭产品名套用其他平台字段 |
| 千问办公 | 自定义 | 确认所用产品入口和额度是否公开展示，再验证读取方式 |
| 豆包办公 | 自定义 | 先核实实际客户端 / 网页及套餐，再确认是否有可读取的额度来源 |
| Grok Bot | 现有 Cursor 账号连接器；也可自定义 | 内置连接读取对应 Cursor 账号，不是 xAI / Grok 官方通用接口；不同产品或账号应另建配置 |
| Muse（[Meta Personal Agent](https://ai.meta.com/muse/)） | 自定义 | 产品身份已明确，额度来源和读取规则仍需实际验证；不预填未经验证的额度路径 |
| 其他 AI 工具 | 自定义 | 自行命名；同样适用于希望尝试的 Qoder、Cursor 或未来工具 |

工具名称只是预设，不会替你选择套餐、猜测额度接口或保证这个产品支持自动查询。所有自定义连接共用[配置规范](custom-sites.md)，仅支持可访问的 HTTPS 额度页、同源只读 GET JSON 或稳定网页数值元素；需要专用客户端协议、跨域认证接口或每次视觉判断的来源可能无法接入。

## 请 Agent 帮忙做一次接入

1. 在目标工具旁点击“自定义接入”；未列出的工具用“其他 AI 工具”。
2. 复制“Computer Use 接入任务”，交给你正在使用、且已启用浏览器 / Computer Use 能力的 Agent。它可以与被监控的工具不同，例如请 Codex 帮忙配置另一款工具。
3. 不清楚官网时，先让 Agent 核实产品身份与官网。产品同名、账号或套餐不明确时先说明，不让 Agent 猜网址或账单归属。
4. 由你本人登录。Agent 检查正常额度页，交付固定读取配置与字段说明；没有可靠来源就说明不支持。
5. 在看板导入、登录、测试，逐项对照网页的账号、套餐、单位、数值和已用 / 剩余含义，最后确认并开启。

**配置任务需要 Agent 能力，日常监控不需要。** 首次分析或以后修复会使用所选 Agent 的额度；看板不会启动 Agent、提交提示词，也不会按计划让模型识别屏幕。目录中的工具并不都提供 Computer Use，具体功能依你使用的版本、地区和管理员设置而定。

## 网站和中转站怎么接

在“网站 / 中转站”入口添加名称及 HTTPS 地址，再使用同一套 Agent 指引。不同网站的布局、单位和接口可能完全不同，必须逐站生成、测试配置，不能只换域名就认为已适配。

已有内置中转站连接继续保留；新站点使用自定义配置。不公开推荐具体中转站，也不要将自己的登录信息、站点配置或实际额度上传到 GitHub。

## 朋友收到项目后如何开始

先按 [安装说明](installation.md) 下载应用并完成首次打开。首次设置里，只启用需要的工具；没有配置或账号尚未登录时可选“稍后设置”。

保存配置后先完成一次成功查询，再观察更新时间。后台约 5 分钟刷新；休眠、离线、限流或登录过期时可能显示旧数据及相应状态。可在设置里暂停某条连接，或从菜单栏退出整个应用。

遇到问题先查看 [README 排障](../README.md#遇到问题) 与 [自定义连接排查](custom-sites.md#测试失败时)。仍有问题请使用 [GitHub 问题模板](https://github.com/bangzhu-commit/ai-balance-board/issues/new/choose)，提供 app 版本、macOS 版本、连接方式和脱敏错误；不要附密码、Cookie、API key、真实配置或原始网页响应。

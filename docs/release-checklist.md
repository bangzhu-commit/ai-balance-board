# 预览发布验收

以下是验收表，不是已完成声明。由执行者逐项记录版本、平台、实际结果；未执行保持空白。

## 自动检查

- [ ] 核心解析与调度检查通过。
- [ ] Chrome 扩展合成环境测试通过。
- [ ] Native Messaging host/client 离线检查通过。
- [ ] 安装脚本语法与 plist 契约检查通过。
- [ ] Swift 构建与 ad-hoc 签名完整性通过。
- [ ] app Resources 包含扩展与维护脚本；普通用户原生注册无需 Python。
- [ ] 白名单源码 ZIP 和 app ZIP 可解压，SHA256 匹配，无用户目录、账号、真实额度、凭据或缓存。

## 干净 macOS 用户或第二台 Mac

- [ ] Apple Silicon/macOS 14+ 下载后可在明确签名限制下完成安装，不要求关闭系统安全防护。
- [ ] 无项目目录、无 Python/Node 的普通 app 首次引导可打开。
- [ ] 可以只启用一个服务、跳过连接、稍后重进设置。
- [ ] 中转站初次登录、失效后重连、错误响应不显示零。
- [ ] Codex 常见安装路径可发现；缺失/未登录有明确下一步。
- [ ] Grok Bot 未安装扩展、Chrome 未启动、未登录、未配对分别可诊断。
- [ ] Chrome 不抢前台；首个服务器读数成功；自然五分钟刷新成功。
- [ ] 拖动、按钮、滚动、菜单栏隐藏/恢复与位置保存正常。
- [ ] 自启关闭/开启、重新登录 macOS、睡眠唤醒、断网恢复正常，重复事件不重复查询。
- [ ] app/扩展升级后能重连，旧版回滚可用。
- [ ] 清除读数、重置配对、取消自启、移除扩展与卸载没有误删个人数据。

## 发布边界

- [ ] 只发布独立导出目录，不从父工作目录执行全量添加。
- [ ] 核对 MIT LICENSE 与版权声明包含在源码及应用下载包中。
- [ ] 明确支持范围：3 个现有服务，非所有中转站或 AI 工具。
- [ ] 明确当前无 Developer ID、公证、扩展商店、自动更新和长期运行保证。
- [ ] 真实平台测试记录使用脱敏结果，不将个人余额写入 README。

GitHub Actions 仅验证离线逻辑，不能代替真实登录、桌面交互、系统权限和长期运行验收。

CI 使用 `macos-15` 并断言 arm64，不使用已退役的 macOS 14 runner；app 最低部署版本仍为 macOS 14。维护时参照 [GitHub runner 官方说明](https://docs.github.com/en/actions/reference/runners/github-hosted-runners)。

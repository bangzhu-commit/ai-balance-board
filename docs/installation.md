# 安装、更新与移除

预览版仅支持 Apple Silicon 和 macOS 14+，尚无 Developer ID 签名/公证；不要关闭系统安全防护来运行。日常使用与服务连接通过 app 内设置完成，无需终端或 Python；首次下载的 SHA256 校验会用到系统自带“终端”。

## 下载与安装

从 [v0.7.0 Release](https://github.com/bangzhu-commit/ai-balance-board/releases/tag/v0.7.0) 下载 `AI-Balance-Board-0.7.0-macos-arm64.zip`。GitHub 自动生成的 “Source code” 是开发源码，不是可双击的应用。

解压后将 `AI 额度看板.app` 拖入“应用程序”再打开。首次遇到系统拦截，先按下面的提示类型判断，再决定是否继续。

## 首次打开被 macOS 拦截

当前预览版尚未经过 Apple 公证，首次打开可能出现开发者无法验证的提示。以下是 Apple 提供的**单个应用授权**操作，不会让应用获得公证。只在你信任本项目、从本仓库 Release 下载且已按[下方步骤](#校验下载文件)确认 SHA256 一致时继续；校验一致本身不代表应用已通过安全审查。

### 先看清提示

| 系统提示（不同 macOS 版本措辞可能略有差异） | 应如何处理 |
| --- | --- |
| “无法验证开发者”或“Apple 无法检查其是否包含恶意软件” | 确认来源与校验值后，可按下方步骤为这个 app 授权 |
| “从互联网下载的 App，确定要打开吗？” | 确认显示的是 `AI 额度看板`，再点击“打开” |
| “将损坏你的电脑”“包含恶意软件”或“App 已损坏” | **停止安装，不按下方步骤强行打开。** 重新从本仓库下载并核对校验值；仍有提示时[报告问题](https://github.com/bangzhu-commit/ai-balance-board/issues/new/choose) |

### 手动允许这一个 app

1. 在“应用程序”中双击 `AI 额度看板.app`。如果出现上表中可手动授权的拦截提示，关闭该提示，保留 app。
2. 打开左上角 **苹果菜单 → 系统设置 → 隐私与安全性**。
3. 向下滚动到“安全性”，找到刚刚阻止 `AI 额度看板` 的说明，点击 **“仍要打开”**。部分版本可能先显示“打开”，再显示确认按钮。
4. 按系统提示输入这台 Mac 的登录密码或使用 Touch ID，再确认“打开”。
5. 看板出现后，按首次设置选择服务并连接。系统会记住这个应用的例外，之后通常可直接双击打开；更换版本后仍可能需要再次确认。

**没有看到“仍要打开”？** 先确认已尝试打开的是“应用程序”中的 app，而不是 ZIP，再回到“隐私与安全性”查看。该按钮通常在尝试打开后一小时内可用。公司或学校管理的 Mac 可能禁止此操作，需要联系管理员；找不到按钮或仍失败时，记录 macOS 版本和完整提示并报告问题。

授权这一步直接在系统设置中完成，无需终端命令，也不需要关闭 Gatekeeper、移除隔离属性或修改系统整体安全策略。截图反馈前请遮住姓名、账号和个人额度。

依据：[Apple：在 Mac 上安全地打开 App](https://support.apple.com/zh-cn/102445) · [Apple：通过覆盖安全设置来打开 App（按钮时限说明）](https://support.apple.com/zh-sg/guide/mac-help/mh40617/27/mac/27)。

## 校验下载文件

1. 在同一个 Release 页面下载 `SHA256SUMS.txt`，用“文本编辑”打开，找到文件名为 `AI-Balance-Board-0.7.0-macos-arm64.zip` 的一行。
2. 打开“应用程序 → 实用工具 → 终端”。输入 `shasum -a 256`，再输入一个空格，先不要回车。
3. 将下载的 **ZIP 文件**从 Finder 拖入终端窗口，系统会自动填入文件路径，再按回车。此命令只读取文件并计算校验值，不会安装或运行应用。
4. 比较终端输出开头的 64 位摘要与校验文件中对应行的摘要，应该完全一致。

摘要不一致时不要安装，应重新下载或报告问题。SHA256 用于核验下载内容一致性，不替代开发者签名或公证。

## 选择工具或添加站点

打开“服务与设置 → 选择工具”，优先选择自己使用的 AI 工具。Codex 与 Grok Bot 提供有特定账户范围的内置连接，所有工具都可选择自定义接入；其他工具入口不表示已有现成的额度适配。

网站或中转站从“添加网站 / 中转站”进入：粘贴网址，复制任务给具备 Computer Use 能力的 Agent，要求其生成可重复查询的配置文件。将文件拖回向导或选择文件，确认域名与指标后保存，再按[自定义接入说明](custom-sites.md)完成登录、测试与核对。配置只保存在本机；不要把真实配置文件、账号或网页响应附在公开 Issue 中。

## 调整窗口

- 拖动顶部图标、标题及其右侧空白区域移动看板；按钮区域仍用于点击。
- 拖动窗口边缘或右下角的斜线手柄等比例缩放。文字、图标、卡片和间距一起变化，位置和比例保存在本机。范围为 80%–160%，受屏幕可用空间进一步限制；连接较多时仍可滚动。
- 默认不置顶。需要常驻上方时，在菜单栏开启“置顶显示”，或在设置“运行方式”中开启“保持看板置顶”。
- 找不到窗口时，从菜单栏选择“显示看板”；只恢复比例时选“恢复默认大小”；位置也不合适时，选择“恢复看板位置与大小”。
- × 只隐藏看板，后台继续查询；完全退出请使用菜单栏退出项。

## 注册与移动 app

先把 app 放入最终安装位置，再在设置中注册本机连接器和登录自启。登录自启采用用户级 LaunchAgent，命令为 `open -g <实际 app 路径>`，不设置 KeepAlive。加载启动项时系统可能尝试后台打开一次，已有实例由单实例锁处理。

注册桥接不替你启用 Chrome 扩展，仍需手动完成 README 中的加载步骤。移动 app 后原启动器路径会失效；应重新注册，遇到冲突先在原位置取消旧注册。不要手改 Chrome 配置。

## 更新

1. 在 Chrome 停用本看板扩展，避免桥接进程继续使用旧版本。
2. 菜单栏退出看板，保留旧 app 作为回滚副本。
3. 用新 app 替换同一路径的旧 app。
4. 启动新 app，重新安装本机连接器，再在 Chrome 重新加载并启用扩展。
5. 确认启用的服务都有新读数；旧数字本身不代表更新成功。

升级保留应用支持目录中的连接配置、最近读数、WebKit 登录会话及系统偏好；不要在更新时删除这些数据。新版未改变自定义配置 schemaVersion 1。升级后仍需检查每个连接的更新时间，登录已过期的服务需要本人重新登录。

预览版尚无自动更新。首次设置可跳过连接，不要求接通全部工具。仅使用 Codex 或自定义连接时，不需要安装 Chrome 组件；Chrome 组件更新步骤只适用于启用了相应连接器的用户。

## 取消自启与卸载

先在设置取消登录自启，在 Chrome 停用扩展。在看板“检查与连接”的 Grok Bot 卡片中展开“移除连接组件”，移除本机组件后，在 Chrome 手动移除扩展、退出看板，把 app 移到废纸篓。开发者也可主动运行下方维护命令移除本机集成。

完整账号会话删除尚未做成一键操作。默认保留 `~/Library/Application Support/AI Balance Board` 中的最近读数与配对记录，以及系统管理的 WebKit 会话和看板偏好。设置里的清除读数只清除额度缓存，不等于退出账号；重置浏览器绑定前要先停用扩展。不要将这些用户数据随安装包分享。

## 开发者维护命令

以下命令行安装脚本需要 Apple Command Line Tools 提供的 Python 3，普通用户优先使用原生设置。路径为示例，请换成实际 app 的绝对路径。

```sh
APP="$HOME/Applications/AI 额度看板.app"
bash "$APP/Contents/Resources/scripts/install-login-item.sh" --register --app-path "$APP"
bash "$APP/Contents/Resources/scripts/install-browser-bridge.sh" --install --app-path "$APP"
bash "$APP/Contents/Resources/scripts/install-login-item.sh" --disable --app-path "$APP"
bash "$APP/Contents/Resources/scripts/uninstall.sh" --integrations --app-path "$APP"
```

`--register` 仅注册已安装 app，不替换应用。`uninstall.sh` 仅移除启动集成与桥接运行文件，不停止其他应用、不删除个人数据。源码开发者仍可运行 `bash scripts/install-login-item.sh --enable` 安装构建产物到用户 Applications 并保留一个上一版；它不会自动结束 UI 或 helper。

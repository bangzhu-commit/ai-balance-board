# 版本说明

## 0.7.1 文本编辑快捷键修复

- 补齐 macOS 标准编辑菜单，让网址、名称及 JSON 输入框可以通过 ⌘V 粘贴，并支持复制、剪切、全选、撤销与重做。
- 编辑命令交给当前输入框处理，不监听全局键盘，也不在后台读取剪贴板。
- 详见 [v0.7.1 发布说明](releases/v0.7.1.md)。

## 0.7.0 整体缩放与网址向导

- 从改变窗口视口改为整体等比例缩放：文字、图标、卡片及操作区域同步缩放。
- 保存缩放比例，迁移旧尺寸；新增恢复默认大小，保留位置恢复与置顶开关。
- 网站接入先粘贴网址，自动规范 HTTPS 域名，页面路径、查询参数和片段不进入 Agent 任务。
- 复制给 Agent 的任务要求交付可重复查询配置；拖入或选择配置文件后自动校验、预览和核对来源。
- 名称编辑与原始 JSON 移入高级设置；导入不自动联网或开启监控。
- 详见 [v0.7.0 发布说明](releases/v0.7.0.md)。

## 0.6.0 工具接入与可调窗口预览

- AI 工具优先目录：Codex、Claude、WorkBuddy、千问办公、豆包办公、Grok Bot、Muse 及其他工具；明确内置连接与需配置入口。
- 所有工具可自定义接入；只提供工具名也可复制 Computer Use 任务，先核实产品、账号、套餐和额度来源。
- 网站 / 中转站独立次级入口，统一导入、登录、测试、核对后开启监控。
- 持久的原生拖动区域；拖边缘或右下角调整大小，刷新不重置位置和尺寸。
- 默认不置顶，可从菜单栏或设置切换；新增恢复窗口位置与大小。
- 修复查询中唤醒/联网事件导致限流后过早再次查询；当前进程每服务至少冷却 300 秒，手动刷新和开关不能绕过。
- 设置新增版本、构建号、下载更新及安装帮助。
- 详见 [v0.6.0 发布说明](releases/v0.6.0.md)。

## 0.5.0 自定义站点预览

- 添加站点、导入配置、登录、测试连接、逐项核对后启用日常查询。
- 同源 JSON 接口或固定 DOM 元素读取；配置不允许脚本、凭据或任意请求。
- 每站点独立会话，动态服务纳入现有刷新调度，测试和周期请求不重复。
- 重新登录、修改配置、取消或删除时废弃旧测试和旧请求结果。
- 内置给 Agent 的接入任务、完整配置规范与合成模板。日常查询不调用模型；首次适配与修复可能使用 Agent 额度。
- 详见 [v0.5.0 发布说明](releases/v0.5.0.md)。

## 0.4.0 预览

- 首次设置与服务选择、可恢复的连接步骤和本机诊断入口。
- 每项服务独立调度和退避；未启用服务不查询，清除或停用后拒绝旧请求回写。
- Codex 常见安装路径检测与手动选择；区分登录、依赖、网络、限流和格式错误。
- 原生设置支持登录自启、本机组件注册/移除、Chrome 绑定重置与脱敏诊断导出，无 Python 运行依赖。
- app 内携带 Chrome 扩展资源，注册不依赖源码目录。
- 维护脚本支持实际 app 路径；提供停用集成的卸载入口。
- 用户说明与开发说明分开，加入隐私、发布验收、离线 CI 和白名单打包。
- 应用下载包附 SHA256，源码采用 MIT License。详见 [v0.4.0 发布说明](releases/v0.4.0.md)。

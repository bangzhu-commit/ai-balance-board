# 隐私与数据边界

- 看板不调用模型，不发送聊天，不上传额度到维护者的服务器。
- 中转站由看板独立 WebKit 会话登录，Codex 调用已登录的 CLI 只读额度接口，Grok Bot 由 Chrome 当前会话查询 Cursor 页面使用的额度接口。
- Chrome 连接器不读取或导出 Cookie、密码、聊天记录；仅传输白名单额度字段与本机协议状态。扩展只允许固定站点，Native Messaging 只允许固定扩展 ID。
- 最近额度保存在本机应用支持目录；浏览器配对信息也只在本机。关闭 app 不会注销平台账号。
- 暂时离线仍会保留上次额度，并标明更新时间/失败状态。清除读数与重置配对是不同操作。
- 本机文件权限不构成同一 macOS 用户下其他进程的安全隔离。不要共享整个用户应用支持目录。

问题报告只需 app/macOS 版本、芯片、服务名称、连接阶段及可复现步骤。不要粘贴 Cookie、Authorization、token、密码、邮箱、原始响应、浏览器配置、真实额度或包含个人信息的截图。若导出脱敏诊断，发送前仍请人工检查；不要直接上传日志目录。

从源码发布时只使用打包脚本的白名单导出。扩展 manifest 的 `key` 是固定 ID 所需的**公开密钥**，不是用户登录密钥；任何私钥或签名证书均不应入库。

## 自定义站点

站点地址、名称和字段映射保存在本机 `custom-sites.json`；登录会话保留在该站点 UUID 对应的独立 WebKit 数据存储中。添加配置不自动联网，登录与测试由用户发起，核对后才开启定时查询。普通 Chrome 登录不会自动复制过来。

导入格式不接受 Cookie、密码、API key、请求头、请求体或任意脚本。读取使用固定程序：同源 GET JSON，或从已配置页面读取指定元素文本。网页自身仍会运行它自己的脚本和加载资源；只添加你信任并授权的站点。没有模型调用、遥测或自动上传配置。

给 Agent 的接入任务会包含你填写的站点名称与地址；使用 Computer Use 时 Agent 也可能处理页面内容和截图，请按该 Agent 的数据政策选择授权范围。不要向公开仓库提交真实配置、截图或响应。首次适配和后续修复可能消耗 Agent 的模型额度。

移除站点会停止查询、删除看板配置和读数，但不退出网页账号；WebKit 会话会保留。诊断导出不包含自定义站点名称、域名、UUID、规则或读数。

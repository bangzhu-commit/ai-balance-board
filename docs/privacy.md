# 隐私与数据边界

- 看板不调用模型，不发送聊天，不上传额度到维护者的服务器。
- FoxCode 由看板独立 WebKit 会话登录，Codex 调用已登录的 CLI 只读额度接口，Grok Bot 由 Chrome 当前会话查询 Cursor 页面使用的额度接口。
- Chrome 连接器不读取或导出 Cookie、密码、聊天记录；仅传输白名单额度字段与本机协议状态。扩展只允许固定站点，Native Messaging 只允许固定扩展 ID。
- 最近额度保存在本机应用支持目录；浏览器配对信息也只在本机。关闭 app 不会注销平台账号。
- 暂时离线仍会保留上次额度，并标明更新时间/失败状态。清除读数与重置配对是不同操作。
- 本机文件权限不构成同一 macOS 用户下其他进程的安全隔离。不要共享整个用户应用支持目录。

问题报告只需 app/macOS 版本、芯片、服务名称、连接阶段及可复现步骤。不要粘贴 Cookie、Authorization、token、密码、邮箱、原始响应、浏览器配置、真实额度或包含个人信息的截图。若导出脱敏诊断，发送前仍请人工检查；不要直接上传日志目录。

从源码发布时只使用打包脚本的白名单导出。扩展 manifest 的 `key` 是固定 ID 所需的**公开密钥**，不是用户登录密钥；任何私钥或签名证书均不应入库。
